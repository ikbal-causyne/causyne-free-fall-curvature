# Free Fall, Proper Acceleration, and Tidal Curvature

**Status:** Preprint, 24 October 2026.

Ikbal Fadilah · [ORCID 0009-0008-4853-135X](https://orcid.org/0009-0008-4853-135X) · ikbal@causyne.com

[![Zenodo DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.23616337.svg)](https://doi.org/10.5281/zenodo.23616337)

This pedagogical note compares proper acceleration, local free fall, and tidal curvature in general relativity. It derives standard Rindler and Schwarzschild results and evaluates illustrative near-Earth scales. It does **not** propose a new field equation or claim experimental discovery. The present draft does not establish an original result sufficient for submission as a research article.

The editable manuscript is [`main.tex`](main.tex); the PDF is [`free-fall-proper-acceleration-tidal-curvature.pdf`](free-fall-proper-acceleration-tidal-curvature.pdf). Build from this directory with `tectonic main.tex --outdir build`. Run `python3 analysis/verify_numbers.py` to reproduce the numerical estimates; the script uses only Python's standard library.
